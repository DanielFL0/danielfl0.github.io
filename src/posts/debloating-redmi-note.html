Adventures in debloating the Redmi Note 14 Pro 5G

It's been a while since I got the Redmi Note 14 Pro 5G. It was sort of a necessary purchase: my old iPhone 13's battery started swelling. The cause is still unknown, but I suspect poor charging habits.

Huge advances in AI, big companies tracking, stealing and selling your data, every modern website competing to collect as much information as possible from its users: these are things we currently have to live with.

But hey, "privacy is for those who have something to hide." Wrong. You have medical records and financial data. Those things are yours, and you should get to decide who you share them with.

I don't want my location shared and stored on some random server. I don't want my financial data used to push the latest PC part deals at me. And I couldn't care less about the newest iPhone release or whatever celebrity scandal Google thinks I should read about.

All of this made me question what my phone actually needs to do, and I want to keep that to a bare minimum.

What I did

I really wanted to try out GrapheneOS, and I'm deeply disappointed in myself for not choosing a Google Pixel instead of the Redmi Note 14 Pro. But at the time I had to decide on the spot. I couldn't afford to do any research or plan ahead. The battery was getting worse by the day and could have become a serious safety hazard.

I won't say much more about GrapheneOS. It only supports Pixel phones, so installing it on my Redmi is off the table.

If I can't have total control over my phone, I at least want a way to minimize what information gets shared with Google and Xiaomi, and that's what this post is about.

I started by figuring out which apps I didn't need. This was the easiest step: most Android phones today come with the manufacturer's own preinstalled apps and games, and I definitely don't need those. Then I downloaded the Android Debug Bridge (ADB) tool and added it to my PATH.

Connecting the phone

ADB can only talk to the phone once USB debugging is on. On HyperOS, that means unlocking Developer options first (Settings → About phone, tap OS version seven times), then turning on USB debugging in Settings → Additional settings → Developer options. With the phone plugged in and the prompt on its screen accepted, this should list it:

adb devices

Taking inventory

Before removing anything, I saved the list of packages on the phone so I'd have something to compare against later:

adb shell pm list packages -s   # system apps
adb shell pm list packages -3   # apps I installed
adb shell pm list packages -d   # disabled apps

Removing apps

Most apps came off with the same command:

adb shell pm uninstall -k --user 0 <package>

This doesn't actually delete system apps. --user 0 removes the app for my user only, while the APK stays in the system partition, and -k keeps its data and cache. That makes it reversible: adb shell cmd package install-existing <package> brings an app back, and a factory reset restores everything.

The exceptions were ShareMe, Mi Mover, Mi Remote, Calendar, Notes, Sound Recorder and Weather. They seem to be preinstalled as regular apps rather than system apps, so the same command deleted them completely, and install-existing can't bring them back. Getting them back means reinstalling them.

Two apps, Calculator and Scanner, refused to uninstall, so I disabled them instead:

adb shell pm disable-user --user 0 <package>

Apps that needed a replacement first

Some apps do jobs the phone can't live without, so before removing them I made sure something else had taken over:

  • Gboard: removing the active keyboard leaves you with no way to type. I switched to HeliBoard and checked it was the default before removing Gboard, with adb shell settings get secure default_input_method.
  • Chrome: Android's WebView, which other apps use to show web pages, is a separate package (com.google.android.webview), so Chrome can go. I confirmed it with adb shell dumpsys webviewupdate.
  • Phone and Messages: I replaced them with Fossify Phone and Fossify Messages and made sure those were the defaults with adb shell cmd role get-role-holders android.app.role.DIALER (and android.app.role.SMS) before removing Xiaomi's and Google's versions.

Replacements

To get apps from somewhere other than Google Play, I installed F-Droid:

adb install F-Droid.apk

I also installed Obtainium, which installs and updates apps straight from their developers' release pages, such as GitHub.

Network

I also set Private DNS (Settings → More connectivity options → Private DNS) to Mullvad's ad-blocking resolver, adblock.dns.mullvad.net. It blocks ads and trackers for every app on the phone, and my DNS queries go to Mullvad, encrypted, instead of to my carrier.

The trade-offs

None of this is free. Here's what I gave up:

  • No Find My Device, so if I lose the phone, I can't locate it.
  • No TalkBack or Google's text-to-speech, so the screen reader and voice output are gone.
  • No updates for Xiaomi's own apps, since GetApps and the System Apps Updater are gone.
  • No Xiaomi Cloud backup or sync.
